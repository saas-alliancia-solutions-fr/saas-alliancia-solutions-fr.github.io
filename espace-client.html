Ligne de commande

Linux Debian / Ubuntu

Le client en ligne de commande fonctionne sur Debian 8, Ubuntu 14.04 et versions ultérieures, avec une architecture AMD64 / Intel 64.

wget -q https://apt.kiwi-backup.com/kiwi-backup.gpg -O - | sudo gpg --dearmor --yes -o /etc/apt/trusted.gpg.d/kiwi-backup.gpg
echo 'deb [arch=amd64] https://apt.kiwi-backup.com/ trixie main' | sudo tee /etc/apt/sources.list.d/kiwi-backup.list
sudo apt-get update && sudo apt-get install kiwi4-cli
Documentation Linux complète
DSM 6 et DSM 7

NAS Synology

Ajoutez le dépôt officiel au Centre de paquets de votre NAS pour installer la version adaptée à son architecture.

  1. Dans le Centre de paquets, ouvrez Paramètres → Sources de paquets.
  2. Ajoutez la source https://syno5.kiwi-backup.com/.
  3. Installez l’application de sauvegarde depuis l’onglet Communauté, puis saisissez votre contrat.
