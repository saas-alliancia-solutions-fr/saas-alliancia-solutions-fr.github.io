Bien démarrer avec SAAS

Le parcours complet pour installer, configurer, sauvegarder et restaurer vos données avec le client Kiwi Backup.

01

Installation

Installer le client sur votre poste

  1. Ouvrez TéléchargementsChoisissez Windows, macOS, Linux ou votre modèle de NAS.
  2. Téléchargez la version recommandéeSur macOS, ouvrez le paquet universel ; sur Windows, lancez l’installeur.
  3. Autorisez les accès nécessairesSur macOS, accordez l’accès complet au disque dans Confidentialité et sécurité.
  4. Ouvrez SAASLors du premier lancement, saisissez le numéro de contrat fourni par Alliancia Solutions.
02

Première configuration

Définir ce qui doit être protégé

  1. Ouvrez « Sauvegarde »La page « Paramétrage de votre sauvegarde » s’affiche.
  2. Ajoutez les dossiers à sauvegarderSélectionnez uniquement les dossiers contenant vos données métier.
  3. Réglez la programmationChoisissez une heure où l’ordinateur est habituellement allumé.
  4. Vérifiez les jours sélectionnésPour une protection quotidienne, cochez du lundi au dimanche.
ConseilÉvitez de sauvegarder des caches ou des fichiers temporaires : ils consomment de l’espace sans valeur métier.
03

Première sauvegarde

Lancer puis contrôler la sauvegarde

  1. Cliquez sur « Calcul »Le client estime le volume et le nombre de fichiers à envoyer.
  2. Cliquez sur « Lancer la sauvegarde »Laissez l’application ouverte pendant le premier envoi.
  3. Attendez le statut « Backup OK »Le bandeau inférieur affiche le volume total et confirme la réussite.
  4. Contrôlez votre espace SAASLa rubrique Sauvegardes indique votre équipement et sa dernière exécution.
04

Restauration

Récupérer un fichier ou un dossier

  1. Ouvrez « Restauration »Sélectionnez la sauvegarde concernée.
  2. Choisissez la datePrenez la version antérieure à la suppression ou à la modification.
  3. Cochez les élémentsVous pouvez restaurer un fichier isolé ou un dossier complet.
  4. Indiquez un dossier de destinationTerminez impérativement le chemin par « / » sur macOS et Linux.
  5. Lancez la restaurationAttendez le message « Restore Ok » avant d’ouvrir le dossier.
Important sur macOSLe dossier restauré peut demander une authentification administrateur. C’est normal : conservez-le ou déplacez ensuite les fichiers vers votre dossier utilisateur.

Vérification finale

Votre protection est opérationnelle si…

  • Le client affiche « Backup OK ».
  • Les jours et l’heure sont programmés.
  • Votre équipement apparaît dans « Sauvegardes ».
  • Une restauration de test a été réalisée.
